# Security Policy

## Reporting a vulnerability

Please report security issues privately rather than opening a public
issue: https://sshush.app/contact.php

Include enough detail to reproduce the problem. You will get an
acknowledgement, and I will let you know when it is fixed.

This is a solo project, so responses may take a few days.

## Scope

This repository contains the SSHush agent - the software that runs
on your own servers. Issues in the agent, its installer, or its
systemd units are in scope.

The SSHush iOS app and the backend it talks to are not in this
repository, but please report issues in those to the same address.
